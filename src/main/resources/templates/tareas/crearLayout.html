Guía para la Generación de Layouts
🛠️ Pasos para crear un layout:
  1. Ingresar nombre del layout: Escriba el nombre en el panel izquierdo (es obligatorio y único).
  2. Cargar Imagen de Planta: Adjunte el plano o foto general de la planta.
  3. Bocetar sectores:
    • Use Rectángulo, Elipse o Polígono / Polínea.
    • Para polígonos: haga clic para agregar puntos; para cerrar el polígono haga clic en el primer punto, doble clic o presione Enter.
    • Los bocetos se muestran en color Azul Traslúcido.
  4. Conformar activos: Presione Conformar Activo, asigne un nombre único y opcionalmente su foto individual. El activo se consolidará en color Verde Traslúcido.
  5. Editar vértices/forma: Use el botón Editar Vértices / Posición para arrastrar puntos o mover figuras.
  6. Guardar en Servidor: Presione Guardar Layout en Servidor para finalizar e integrar los enlaces dinámicos al proyecto.
